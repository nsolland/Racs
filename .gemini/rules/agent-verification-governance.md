# Public automated-contribution guidance

This adapter applies only to the public RACS repository.

Automated contributors must verify claims against public repository state, public CI, versioned specification artifacts, and public conformance evidence. A producing agent must not treat its own assertion as independent verification.

Do not use or expose private repository catalogues, private dependency maps, unpublished component topology, internal delivery state, or research context when working in this public repository.

Missing public evidence remains unverified. Historical tests are not evidence of current green state. Public repository source and current remote state control public delivery claims.
