## Update rule

Every new normative object, schema or extension must be added here before release.

The record must identify:

- originating requirement
- author or responsible maintainer
- first commit
- external references
- applicable license
- whether the object is normative, experimental or superseded

Unclear origins must be marked `unresolved` and excluded from normative releases until reviewed.
