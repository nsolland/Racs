## Update rule

Every new normative object, schema or extension must be added here before release.

The record must identify:

- originating requirement class
- author or responsible maintainer
- first commit
- external references
- applicable license
- whether the object is normative, experimental or superseded

Private component names, internal repository relationships, build sequencing and unpublished research are not required for this public provenance register and must not be added merely to explain origin.

Unclear origins must be marked `unresolved` and excluded from normative releases until reviewed.
