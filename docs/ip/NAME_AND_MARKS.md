# RACS Name and Marks

## Project name

RACS means REHT Action Control Standard.

The name identifies the VALO-originated protocol project in this repository.

## Distinction from archived ACS

RACS is not the Agent Control Standard and is not a continuation, fork, rebrand or endorsed implementation of that project.

The archived `nsolland/ACS` repository is separate historical third-party material.

## Use of the RACS name

The RACS name may be used accurately to describe:

- the specification published from this repository
- conforming implementations
- compatibility testing
- research or commentary about the standard

It must not be used to imply:

- certification where none has been issued
- endorsement by VALO
- ownership of the standard by an unrelated implementation
- compatibility without conformance evidence

## Conformance language

Preferred terms:

- `RACS-compatible`
- `implements RACS version X`
- `evaluated against RACS profile X`

Reserved terms until a certification process exists:

- `RACS-certified`
- `official RACS implementation`
- `approved by RACS`

## Naming review

Before public launch, complete trademark and naming-conflict searches in intended markets. Repository creation and this policy do not establish registered trademark rights.
