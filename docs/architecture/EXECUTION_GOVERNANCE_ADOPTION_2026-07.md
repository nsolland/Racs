# RACS public architecture boundary

RACS is a public, vendor-neutral protocol and conformance surface for deterministic governed-decision and execution-evidence contracts.

This public repository intentionally does not publish private portfolio topology, internal component ownership, unpublished implementation architecture, delivery sequencing, or private dependency maps.

For current public semantics, use:

- `SPECIFICATION.md`;
- the normative files under `spec/`;
- public schemas, validators, bindings, and test vectors;
- `CONFORMANCE.md` and repository release history.

A public interoperability contract must be sufficient to implement or verify RACS without requiring knowledge of any private runtime or research architecture.
