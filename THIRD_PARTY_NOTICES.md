# Third-Party Notices

RACS is a clean-room specification repository.

No third-party source code or specification text is currently included.

## External projects not included

The external Agent Control Standard project and the archived `nsolland/ACS` repository are not dependencies of RACS and are not incorporated into this specification.

Any future third-party material must be listed here with:

- project name

- copyright holder
- license
- files or sections used
- modification status
- reason for inclusion

Absence from this file does not authorize copying external material.
